# Security

The site is static (HTML, CSS and JavaScript on GitHub Pages) and the games run
entirely in the visitor's browser. They collect no data and make no network
requests.

If you find a security problem (for example, a game that can run untrusted
code, or a way to inject content into a page), please **do not open a public
issue**. Email contact@yantrika.in, or use GitHub's "Report a vulnerability"
button on the Security tab. We will reply as soon as we can.
